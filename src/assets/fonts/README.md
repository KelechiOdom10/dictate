# Geist

Variable Latin WOFF2 from `@fontsource-variable/geist` 5.2.8:
https://cdn.jsdelivr.net/npm/@fontsource-variable/geist@5.2.8/files/geist-latin-wght-normal.woff2

Bundled locally for offline use. CSS exposes the app’s weights 400/500/600.
Other scripts fall back to the platform fonts. OFL.txt is the SIL Open Font
License shipped with that package (https://github.com/vercel/geist-font).
