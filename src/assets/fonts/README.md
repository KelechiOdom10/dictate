# Instrument Sans

Variable Latin WOFF2 from `@fontsource-variable/instrument-sans` 5.2.6:
https://cdn.jsdelivr.net/npm/@fontsource-variable/instrument-sans@5.2.6/files/instrument-sans-latin-wght-normal.woff2

Bundled locally for offline use. CSS exposes the app’s weights 400/500/600.
Other scripts fall back to the platform fonts. OFL.txt is the upstream SIL Open
Font License from https://github.com/google/fonts/tree/main/ofl/instrumentsans.
